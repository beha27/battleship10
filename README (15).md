# ⚔️ Морской Бой 10×10 (4 Корабля) — P2P PvP & PvE

Актуальная версия браузерной игры «Морской бой» 10×10 с ручной расстановкой флота, PvP-режимом через PeerJS (с авто-подтверждением readiness) и автоматической отрисовкой контуров вокруг уничтоженных кораблей.

## 🚀 Комплектация флота:
1. 🛳️ **1× 4-палубный** (Линкор)
2. 🛳️ **1× 3-палубный** (Крейсер)
3. 🛳️ **1× 2-палубный** (Эсминец)
4. 🛳️ **1× 1-палубный** (Катер)

## 📡 PvP Особенности:
- **Авто-рукопожатие (Heartbeat Ready Ping)**: отправка сообщений `ready` каждую секунду, пока оба игрока не подтвердят старт боя.
- **Обход NAT**: Поддержка публичных STUN-серверов Google.
